# WPF.YS.Framework

> إطار عمل WPF محايد لبناء تطبيقات متكاملة: DI، Navigation، Menu، Reports، Data (Offline-first)، View Templates، Custom Controls — بعقود نظيفة وبلا ارتباط بمكتبات UI معيّنة.

[![CI](https://github.com/YS-Laith/WPF.YS.Framework/actions/workflows/ci.yml/badge.svg)](https://github.com/YS-Laith/WPF.YS.Framework/actions/workflows/ci.yml)

![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ الميزات

| الميزة | الوصف |
|---|---|
| 🧩 **محايد** | لا يعتمد على Prism أو أي مكتبة UI |
| 🎯 **Contracts-first** | واجهات لكل شيء، Bases اختيارية |
| 📦 **Offline-first** | SQLite + Outbox + Sync Engine |
| 🎨 **Custom Controls** | Attached Properties + Themes |
| 🖥️ **View Templates** | Grid / Card / Tree / Timeline / Feed |
| 🔌 **Backend-agnostic** | REST، OData، XPO، GraphQL |
| 🔍 **Auto-scan** | Attributes + AssemblyScanner |
| ⚡ **Async-first** | كل شيء Async + CancellationToken |
